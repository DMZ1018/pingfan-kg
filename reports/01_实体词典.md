# 01 实体词词典（Entity Dictionary）

> 语料：《平凡的世界》三部梗概（三幅图片转写，21 句 / 1103 字）
> 产物：`data/dict/entity_dict.json`、`data/dict/entity_dict.csv`、`data/dict/seed_entities.csv`
> 脚本：`src/build_entity_dict.py`

## 1. 为什么先建词典

三部梗概只有 1103 字，却密集出现了 14 个人物、17 个地点、9 个机构。这种"小语料、高实体密度、强领域性"的场景里，词典不是可有可无的辅助资源，而是**唯一的稳定先验**：

1. **归一化**：正文里"少平/孙少平""晓霞/田晓霞""窑/砖窑"混用，不做别名归一，后续关系抽取会把同一个人拆成两个节点，图谱直接断裂。
2. **类型约束**：`丈夫`、`妻子`、`父亲` 这类指代型称谓只有放进词典并标注所指，才能支撑"婚恋/亲属"关系的方向判定。
3. **可复现的基线**：词典给出的是可解释、可审计的上界，用来衡量神经网络到底学到了什么。

## 2. 类型体系

| 类型 | 中文 | 说明 | 示例 |
|---|---|---|---|
| PER | 人物 | 具名人物，不含泛称 | 孙少平、田福堂、金波之妹 |
| LOC | 地点 | 自然/行政/场所 | 原西县、山西、砖窑、河坝 |
| ORG | 机构 | 学校、机关、组织 | 原西县高中、县革委、省报 |
| TIME | 时间 | 时点、时段、年龄外的时长 | 1975年初、1982年、两年后 |
| EVENT | 事件 | 可命名的事件/事变 | 十一届三中全会、旱灾、抗洪采访 |
| POLICY | 政策/运动 | 制度、运动、政策 | 责任制、农业学大寨 |
| POS | 身份/职务 | 职业、头衔、亲属角色 | 村支书、记者、丈夫、父母 |
| NUM | 数量 | 金额、年龄等数值 | 一万五千元、27岁 |
| DIS | 疾病 | 疾病名称 | 肺癌 |

设计取舍：

- **不设"作品"类**：语料中没有书名、篇名，加了就是空类。
- **POS 单列**：如果把"村支书""记者"并进 PER，`田福堂—村支书` 这种"任职"关系就会退化成"同类实体"关系，图谱里丢掉关键语义。
- **亲属称谓单列**：`父亲/女儿/丈夫` 在文本中既是实体提及，又是关系触发词，单列成 POS 可以让"实体识别"和"关系触发"两件事解耦。

## 3. 构建流程

```
seed_entities.csv (人工种子：名、类型、别名、释义)
        │
        ├─ 别名归一：全名 + 别名 → 同一 eid
        ├─ 语料回扫：最长匹配统计词频、记录首现句
        ├─ 类型编号：TYPE_001 形式，稳定可引用
        └─ 人工复核：删除误收词、补全指代型称谓
```

频次统计用**最长匹配**而不是简单子串计数：`孙少平` 与 `少平` 在文中重叠，简单计数会把一次提及算两遍。脚本里按 `(start, -length)` 排序后贪心取不重叠片段。

## 6. 别名与指代处理

| 规范名 | 别名/指代 | 处理方式 |
|---|---|---|
| 孙少平 | 少平 | 别名直接归一 |
| 孙少安 | 少安 | 别名直接归一 |
| 田晓霞 | 晓霞、女友 | 别名归一；"女友"为关系型指代，仅在关系层使用 |
| 田润叶 | 润叶 | 别名直接归一 |
| 田润生 | 润生 | 别名直接归一 |
| 秀莲 | 贺秀莲 | 别名归一（小说全名） |
| 砖窑 | 窑 | 别名归一，避免"窑"被当成未登录词 |
| 李向前 | 丈夫（P2-S04、P3-S05） | 依赖上下文消解，词典只登记"丈夫"为 POS，不强行绑定 |
| 田福堂 | 父亲/父母（P1-S06、P3-S05） | 同上 |
| 金波之妹 | 她（P3-S06） | 代词不进入词典，交给指代消解 |

**没有做**的事：没有把"他/她/他们"登记为实体。代词是句法现象而不是词汇现象，硬塞进词典会让 NER 精确率大幅下降，也会让后续关系抽取产生大量自环。

## 7. 局限与扩展

1. **规模**：80 词条覆盖 1103 字够用，但放大到整本小说（约 100 万字）需要 3000+ 词条，人工维护成本不可接受，应改为"种子词典 + 远程监督 + 主动学习"的迭代方式。
2. **指代**：词典只能登记"丈夫=李向前"这类**全局**指代；"她的弟弟润生"这种**局部**指代必须靠篇章级指代消解，词典无能为力。
3. **类型粒度**：LOC 把"山西"（省）和"砖窑"（设施）放在同一类，做图谱查询时 `MATCH (n:LOC)` 会把行政区和建筑物混在一起。生产环境建议二级类型（ADMIN/FACILITY/NATURAL）。
4. **时效**：语料是 1975—1982 年的陕北农村，`公社`、`生产队`、`县革委` 都是历史机构，现代语料上这些词条会全部失效。
