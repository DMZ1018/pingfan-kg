# 关系抽取提示词（LLM 分支实际使用）

## 系统提示

```
你是中文关系抽取专家。只使用句子中出现的信息，不要补充小说其他章节的情节。
```

## 用户提示

```
【任务】从句子中抽取关系三元组，输出 JSON。

【实体类型】
PER/LOC/ORG/TIME/EVENT/POLICY/POS/NUM/DIS（同 NER 规范）

【关系类型（只用这些，不要自造）】
婚恋：夫妻、恋人、恋爱、爱慕、青梅竹马、相亲、表白
亲属：父亲、父女、兄弟、姐弟、兄妹
社交：同学、朋友、遇见、邂逅、介绍
任职：任职于、担任、职务、成为、身份、毕业、就读于
空间：到、回到、发生于、牺牲于、受伤于
组织：领导、组织、召开、推行、实行、推广、抵制、反对、抵触、破坏、抢水
支持：帮助、救助、救、出资、通知、承认
冲突：揭发、拒绝、说破
经营：建、经营、扩建、贷款
归属：属于、隶属
事件：确诊、牺牲、受伤、致残

【方向约定】
- "A的父亲B" → [B, 父亲, A]（子 → 父）
- "A与B结婚" → [A, 夫妻, B]
- "A任职于B" → [A, 任职于, B]
- "A的职务是B" → [A, 职务, B]

【硬性约束】
1. 头和尾必须是具体实体；"丈夫/妻子/父亲/她"必须替换成具体人名，替换不了就丢弃该三元组。
2. 禁止自环（头 == 尾）。
3. 禁止输出句子中没有依据的三元组。
4. 同一句子内允许输出多条。

【输出格式】
{"triples": [["田晓霞", "父亲", "田福军"], ["田福军", "任职于", "县革委"]]}

【句子】
{text}
```

## 说明

- 原始输出：`data/llm/triples.json`（77 条）。
- 指代型三元组（10 条）依赖上下文，提示词允许模型跨句引用前文已出现的人物，但要求在本句内能找到指代依据。
- 同一模型既做标注又做抽取，存在乐观偏差，见 `reports/03_关系三元组.md` 第 4.3 节。
