# 实体抽取提示词（LLM 分支实际使用）

## 系统提示

```
你是中文信息抽取专家。请严格按给定类型体系抽取实体，不要引入外部知识。
```

## 用户提示

```
【任务】对下面这句话做命名实体识别，输出 JSON。

【类型体系】
PER    人物（具名，不含"他/她/丈夫"这类代词与泛称）
LOC    地点（行政区、自然地理、场所、设施）
ORG    机构（学校、机关、组织、报社、生产队）
TIME   时间（时点、时段）
EVENT  事件（可命名的会议、灾害、事故、采访任务）
POLICY 政策/运动/制度
POS    身份/职务/亲属角色（教师、村支书、丈夫、父母、徒弟）
NUM    数量（金额、年龄）
DIS    疾病

【标注规范】
1. 扁平标注，不允许嵌套。遇到"金波之妹"整体标为一个 PER，不再单独标"金波"。
2. 代词（他/她/他们）不标。
3. 泛称（农民、灾民、朋友）若在句中充当角色，标 POS；若只是修饰语，不标。
4. 边界取最小完整语义单位："县革委副主任"拆成 ORG(县革委) + POS(副主任)。
5. 同一句出现多次同一实体，每次都要输出，用第三个字段标注第几次出现。

【输出格式】
{"entities": [["孙少平", "PER", 1], ["郝红梅", "PER", 1], ...]}

【句子】
{text}
```

## 说明

- 金标准由人工按同一份规范先行标注（`data/gold/annotations.json`），LLM 抽取时**未参考金标准**，只依据原文与本提示词。
- 由于标注者与抽取模型同源，指标存在乐观偏差；严谨做法是换独立模型盲测。
- 原始输出：`data/llm/ner.json`。
